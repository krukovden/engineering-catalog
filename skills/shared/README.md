# skills/shared

Used by two or more audiences — the build enforces it (§3.1).

| Name | Description |
|---|---|
| [ado-credentials](ado-credentials/SKILL.md) | Preflight for Azure DevOps access — answers whether a credential is present, whether it still works against the organization, and exactly what to do if not. Run it first, then continue with the skill that needs Azure DevOps (for example qa-ado-work-item to file a bug); that skill starts only after this one answers ok. Also use when the user asks which Azure DevOps projects are connected, wants to add or remove a project (they give a board link and code links), says they now work in or want to switch to another project or team, or needs to enter or replace their PAT — on Windows all of it runs through this conversation, the user never runs a script. On macOS/Linux it checks the az CLI login and the azure-devops extension. |
| [catalog-freshness](catalog-freshness/SKILL.md) | Once per session, before other work, check whether the installed engineering catalog is outdated — run the freshness script (it is cheap, needs only git, and stays silent when nothing is due) and relay its one-line hint to the user if it prints one. Applies to every project where the catalog is installed, on Claude Code and on GitHub Copilot alike. Also use when the user asks which version of the engineering catalog is installed; then run the script with --version (-Version) and answer with the line it prints. |
| [grilling](grilling/SKILL.md) | Grill the user relentlessly about a plan, decision, or idea before any of it gets built — walk the decision tree one question at a time until there is shared understanding. Use when the user wants to stress-test their thinking, says "grill me", asks to sharpen or pressure-test a plan, or is about to start building something whose requirements are still fuzzy. |
| [memory](memory/SKILL.md) | Project memory for every session — read the project's memory/index.md before proposing anything, load a unit file when work touches it, and write an entry only when a change is hard to reverse, not obvious without context, and the result of a real trade-off. Use when starting work in a project that has a memory folder, when about to propose an approach, and after a decision that meets the three-part test. |
| [memory-init](memory-init/SKILL.md) | Initialise project memory in this repository — choose the store, create the memory folder and index, point Claude and Copilot at it, install the post-commit hook, then fill the index from the code with honest evidence grades. Run once per project; safe to run again. |
| [unslop](unslop/SKILL.md) | Cut AI tells from any writing — scan for the listed patterns, rewrite with meaning and tone kept, self-audit. Use when the user says "unslop this", "remove the AI tells", "make this sound less like AI", or when another skill hands over a text it has drafted, such as a commit message or a PR description. |
