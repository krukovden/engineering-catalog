Also run `states discover` once per project before the first move. |
| [ado-credentials](ado-credentials/SKILL.md) | Preflight for Azure DevOps access — answers whether a credential is present, whether it still works against the organization, and exactly what to do if not. Also use when the user asks which Azure DevOps projects are connected, wants to add or remove a project (they give a board link and code links), says they now work in or want to switch to another project or team, or needs to enter or replace their PAT — on Windows all of it runs through this conversation, the user never runs a script. On macOS/Linux it proves the PAT in AZURE_DEVOPS_EXT_PAT when one is set, else the az CLI login and the azure-devops extension. |

| [catalog-freshness](catalog-freshness/SKILL.md) | Once per session, before other work, check whether the installed engineering catalog is outdated — run the freshness script (it is cheap, needs only git, and stays silent when nothing is due) and relay its one-line hint to the user if it prints one. Applies to every project where the catalog is installed, on Claude Code and on GitHub Copilot alike. Also use when the user asks which version of the engineering catalog is installed; then run the script with --version (-Version) and answer with the line it prints. |
| [grilling](grilling/SKILL.md) | Grill the user relentlessly about a plan, decision, or idea before any of it gets built — walk the decision tree one question at a time until there is shared understanding. Use when the user wants to stress-test their thinking, says "grill me", asks to sharpen or pressure-test a plan, or is about to start building something whose requirements are still fuzzy. |

Use when starting work in a project that has a memory folder, when about to propose an approach, and after a decision that meets the three-part test. |
| [memory-init](memory-init/SKILL.md) | Initialise project memory in this repository — choose the store, create the memory folder and index, point Claude and Copilot at it, install the post-commit hook, then fill the index from the code with honest evidence grades. Run once per project; safe to run again. |

Use when the user says "find where this breaks", "search all our repositories", "which project has this code", "did this change recently", "check Warehouse, Reports and Sidecar", names more than one repository to look in, or another skill needs to look at code it does not have open. Not for one repository the user is already working in — search that one directly. |
